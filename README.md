# 🎀 Deutsch Lernen - Running Quiz Game 💖✨

A fun, interactive, and cute web application built with HTML, CSS, and pure JavaScript to help users learn German! Inspired by the dodge/running button meme, the wrong answer runs away when you try to hover or click on it, encouraging users to pick the right option! 😉

---

## 🌐 Live Demo

🔗 **Try the Quiz Live on Vercel:** [ https://deutsch-lernen-beta.vercel.app/ ]

---

## ✨ Features

- 💅 **Cute & Modern Aesthetic:** Soft pink gradient palette, smooth animations, and clean typography (`Plus Jakarta Sans`).
- ⚡ **Running/Dodging Button Mechanics:** The wrong answer flees around the screen, making the quiz hilarious and interactive.
- 🎯 **Dynamic Quiz Builder:** Instructors can easily add multiple custom German questions and answers on the fly.
- 💌 **Custom Success Message:** Instructors can personalize the congratulations message for students at the end.
- 🎉 **Confetti Celebration:** Uses `canvas-confetti` to trigger a colorful celebratory burst from both sides upon completion!
- 📱 **Fully Responsive:** Smooth layout adaptable for all mobile devices, tablets, and desktops.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic and clean markup layout.
- **CSS3:** Custom Variables, Flexbox, Modern Gradients, Responsive Design & CSS Animations.
- **Vanilla JavaScript (ES6+):** DOM Manipulation, Dynamic Logic & Event Listeners.
- **Canvas Confetti Library:** CDN integration for end-game celebrations.
